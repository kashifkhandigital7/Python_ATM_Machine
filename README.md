Python ATM Machine

A simple console-based ATM-Machine program built with Python.

Features

* 3-attempt PIN authentication
* Temporary card blocking after 3 incorrect attempts
* Balance inquiry
* Cash deposit
* Cash withdrawal
* PIN change
* Funds transfer to a 13-digit account
* Safe exit option

Starting Balance

The ATM starts with a balance of Rs. 500,000.

## Python Concepts Used

* Variables
* Lists
* while loops
* if/elif/else
* User input
* List methods
* Basic validation

How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the Python file.
4. Enter one of the valid PINs to test the program.
